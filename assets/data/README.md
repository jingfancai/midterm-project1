# 목적지 데이터

`destinations.json`은 Flutter 앱에 포함되는 로컬 asset입니다. 50개 도시, 35개 국가와
기존 여행 호환용 제주도·강원도 2개 지역을 담습니다. 국가/도시 통계는 지역을 도시로 추정하지 않습니다.

- `schemaVersion`: 현재 1.
- `defaultPhotoUrl`: 사진 대응이 없는 목적지의 공통 HTTPS 사진.
- `cities`: 도시별 고유 `id`, ISO `countryCode`, 한국어 `countryName`, `names.en/ko/zh` 필수.
- `regions`: 같은 구조지만 도시 수에는 포함하지 않는 도/섬 단위 목적지.
- `aliases`: 선택 사항. 명확한 다른 표기만 추가하며 다른 목적지의 별칭과 충돌하면 안 됩니다.
- `photoUrl`: 선택 사항. 실제 목적지와 일치하는 고정 HTTPS 사진만 지정합니다. 생략 시 기본 사진.

도시 ID는 중복 제거와 기존 데이터 호환을 위해 유지하세요. 기존 7개 도시의 확인된 고정 사진을
유지하며, 새 도시의 확인되지 않은 사진을 임의로 지정하지 않습니다.

앱은 `main()`에서 파일을 한 번 읽고 검증한 다음 시작합니다. 이후 검색/통계는 메모리에서
동기적으로 처리하므로 외부 지도 API나 런타임 데이터 다운로드가 필요하지 않습니다.
`lib/destinations.dart`는 로딩·검증·이름 매칭만 담당합니다. 새 도시를 추가할 때 Dart 도시 목록은
수정할 필요가 없습니다. `pubspec.yaml`의 asset 등록을 유지하세요.

검증: `flutter analyze`, `flutter test`. 테스트는 3개 언어의 모든 이름과 별칭, 도시/국가 개수,
중복 별칭·ID, 필수 필드, 고정 사진 및 기존 UI/저장 기능을 확인합니다.
