# 디자인 가이드 — Polarsteps v2 중간 UI/UX Prototype

이 문서는 현재 A/B/C 화면, 요소 번호와 Nielsen 원칙의 기준이다.
최소 수정 요청에 따라 원래 상호작용·계산을 복구하되 서버 쓰기·영구 저장은 제거한다.
이 버전은 기능 보존안이며 교수 감점 규칙을 모두 충족한다고 주장하지 않는다.
AGENTS.md의 실제 로직·업무 상태 미구현 원칙과 달리, 사용자의 명시적 요청으로 아래 세션 기능을 유지한다. 위험은 11절에 기록한다.
PPT 파일 자체는 저장소에 없으며, `자가평가.md`와 `셀프논증.md`에 적힌 발표자료 부록 B5 요구를 참고했다.
실제 앱 리뷰·발표 영상·교수의 최종 승인 근거는 아직 제공되지 않았으므로 만들어 적지 않는다.

## 4. 디자인 가이드 글

나의 여행 목록은 대표 사진과 여행 제목으로 항목을 알아보기 쉽게 한다. 사진 위 라벨과 버튼은 두지 않고,
사진 아래 제목 오른쪽에 즐겨찾기·삭제 아이콘을 둔다. 다음 줄은 날짜와 목적지다. 600dp 미만은 목록의
16:9 표지, 그 이상은 격자를 유지한다. 색상·카드 둥근 모서리·여백·사진 자원은 기존 디자인 그대로다.
B는 큰 표지 아래 20dp 간격을 두고 여행 정보를 표시한다.
C는 통계 → 방문 장소 지도 → ALL MY TRIPS 순서다. Featured Memory(대표 여행)는 제거한다.
C 전체를 스크롤할 수 있어 작은 창과 긴 여행 목록에서도 지도·전체 기록·닫기에 접근할 수 있다. 외부 지도 서비스·인증·GPS·AI·추천 처리는 없다.

## 6. GET 전용 데이터와 메모리 상호작용

HTTP는 lib/api.dart의 GET /items, GET /notes?itemId= 두 종류뿐이다. POST/PUT/PATCH/DELETE,
일반 HTTP method를 받는 쓰기 함수, 생성/편집/삭제 API가 없다. 로컬 서버도 읽기 전용 메모리 라우터이며 DB에 쓰지 않는다.
TripEditor 입력 검증 후 추가/편집 결과를 A/B의 메모리 콜백으로 전달한다. 새 여행에는 세션 전용 음수 ID를 부여한다.
즐겨찾기·삭제·실행 취소는 현재 세션 목록에만 반영된다. 삭제 SnackBar는 기존 알림을 정리하고 보통 4초,
접근성 설정 시 10초 동안 실행 취소를 제공한다. 새로고침은 GET 원본을 다시 읽어 세션 변경을 초기화한다.
앱 재실행/브라우저 새로고침도 변경을 잃는다. shared_preferences/파일/DB 등 로컬 영구 저장도 없다.

## 7. 여행 통계와 날짜 분류

TripDates와 오늘 날짜를 비교해 예정/진행/완료/날짜 미정으로 분류한다. TripSummary는 삭제되지 않은
현재 세션 여행 수·즐겨찾기 수·분류별 수·여행 기간 합계를 계산한다. 기간 합계에는 미래 여행도 포함되며
방문 도시/국가만 이미 시작한 여행으로 제한한다. 날짜가 잘못되거나 없는 여행은 방문 집계에서 제외한다.
한·영·중 별칭을 같은 도시 ID로 통합하고 도시/국가를 각각 중복 제거한다. Tokyo+Osaka는 2도시·1국가다.
제주도·강원도 같은 지역 항목은 국가 수에는 반영하지만 도시 수에는 넣지 않는 기존 정책을 유지한다.
추가·편집·즐겨찾기·삭제·복원 후 A 통계와 다시 연 C가 최신 메모리 데이터를 사용한다. 타이머나 실시간 통신은 없다.
이 계산은 실제 로직이므로 교수의 감점 위험이 남는다.

## 8. 검색·정렬·목적지 인식·사진

검색은 제목·날짜/목적지·태그에서 공백으로 나눈 모든 검색어를 대소문자 구분 없이 찾는다.
즐겨찾기 필터는 현재 메모리의 선택값을 사용한다. 정렬은 각 날짜 그룹 안에서 최신/과거 출발일/이름순을 적용한다.
목적지는 로컬 destinations.json의 한·영·중 도시 이름과 별칭으로 국가·도시 ID·고정 사진을 찾는다.
인식하지 못하면 한국어 안내와 중성 기본 표지를 쓰고 방문 도시·국가 집계에서 제외한다. 임의 국가 추측은 없다.
홈·상세·회고는 Item.photoUrl과 기존 NetImage를 공유한다. 랜덤 사진·외부 지도/지오코딩 API는 없다.
검색·정렬·집계·목적지 인식은 실제 처리이며 단순 UI 장면으로 가장하지 않는다.

### C-6 방문 장소 지도

세계 지도는 앱에 포함된 assets/images/world_map.png를 사용하며 Natural Earth 공개 도메인 육지 윤곽을
기존 녹색 톤으로 그렸다. 지도 타일·지도 API·GPS·지오코딩·새 네트워크 호출은 없다. 출처는 assets/images/README.md다.
전체 경도 -180~180, 위도 -90~90의 정거원통도법(Plate Carree)으로 PNG와 Marker를 같은 비율로 배치한다.
destinations.json의 50개 도시 모두 대략적인 도심 좌표를 갖는다. 이는 관광 도시 예시 위치이며 개인 위치가 아니다.
통계와 같은 isVisitedTrip 조건을 공유하며 이미 시작하고 날짜가 유효한 미삭제 여행만 표시한다.
한·영·중 이름은 기존 cityKey로 묶어 Marker 하나에 해당 여행 제목을 모은다. 같은 도시의 여러 여행은 하나의 점이다.
지역(제주도·강원도), 미인식 장소, 좌표 없는 장소는 도시 Marker로 추측하지 않는다. 지역은 기존 국가 통계 정책을 유지한다.
Marker가 가까이 겹치면 36dp 이내 도시들을 함께 Dialog에 보여 누락 없이 확인할 수 있다.
표시할 도시가 없으면 한국어 안내를 보여 준다. 세션 내 추가/수정/삭제 후 C 재진입 시 현재 데이터로 지도도 갱신한다.
별도 화면·확대/축소·길찾기·경로 저장은 추가하지 않는다. C-7은 기존 AlertDialog와 Text/Column만 재사용한다.

## 9. 범위·개인정보·외부 서비스

별도 ProfileScreen을 제거하고 기존 A 아바타는 설명 모달로 처리한다. A/B/C 이외 독립 페이지는 없다.
로그인·회원가입·결제·개인정보 수집·유료 API·실시간 통신은 없다. 입력은 가상의 여행명·목적지·메모만 시연하며
서버/기기에 저장·전송하지 않으며 화면 세션 메모리에서만 변경한다. 공개된 예시 여행 데이터만 GET으로 읽는다. 사진 CDN 접근은 기존 고정 사진 표시만 담당한다.

## 10. 데이터·사진 자원과 시험 범위

destinations.json의 50개 도시·35개 국가와 기존 지역 자료, 확인된 고정 사진·라이선스는 보존한다.
앱 시작 시 asset을 읽고 검증하는 것은 표시 자원 로딩이며 외부 지오코딩/추천 API를 호출하지 않는다.
알 수 없는 사진은 중성 표지로 대체하고 실패 시 기존 이미지 아이콘을 사용한다.
테스트는 사진과 반응형 레이아웃·A/B/C 이동·Loading/Error/Empty·GET 오류 복구·검색·정렬·집계·별칭 인식·지도 Marker/가까운 도시 Dialog·세션 변경/복원과 GET 재조회 시 초기화를 확인한다.
기존 테스트 파일을 유지하고 서버 저장 대신 세션 전용 계약으로 갱신한다. 서버 쓰기 금지는 별도로 검증한다.

## 11. 교수 감점 규칙에 따른 남은 위험

| 규칙 | 현재 구현과 위험 |
|---|---|
| 실제 로그인·결제 | 구현하지 않음 |
| POST/PUT/PATCH/DELETE·영구 저장 | 앱 GET 전용, 서버 쓰기 차단, 로컬 저장 없음. 메모리 편집을 영구 저장이라고 설명하지 않음 |
| 상태관리 구현 | **위험 있음**: 패키지는 없지만 setState/콜백으로 여행·즐겨찾기·삭제·기록 상태를 변경함 |
| 실제 로직 | **위험 있음**: 검색, 정렬, 날짜 검증·분류, 기간 합산, 도시/국가 중복 제거, 목적지 인식·방문 지도 Marker 계산은 실제 로직임 |
| 가이드에 없는 화면 | 독립 ProfileScreen 제거, A/B/C와 기존 모달만 유지 |
| 유료 API·개인정보 | 추가하지 않음. 기존 고정 공개 사진 CDN과 가상 여행 데이터만 사용 |

기능을 보존하라는 사용자의 명시적 요청을 반영했다. 위험 기능을 임의로 삭제하거나 가짜 결과로 바꾸지 않는다.
실제 PPT/PDF·앱 리뷰·발표 영상은 제공되지 않아 최종 일치 여부를 확인할 수 없다.
별도 자가평가/셀프 논증 문서의 미작성 제출 증빙도 사람이 작성해야 한다. 통과 점수·교수 승인을 보증하지 않는다.
