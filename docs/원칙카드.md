# Polarsteps v2 — Nielsen 원칙 카드

실제 사용자 리뷰나 영상은 제공되지 않았다. 아래 근거는 구현 구조와 회귀 테스트이며 리뷰를 지어내지 않는다.

| 원칙 | 적용 요소·화면 | 설계 판단 | 검증 |
|---|---|---|---|
| P01 상태 가시성 | A-4/A-6, B-7, C-3 | 비동기 GET 상태를 표시하고 통계는 예시임을 고지 | 로딩/오류/빈 상태와 통계 문구 테스트 |
| P02 실세계 일치 | A-2/B-3/C-2 | 여행 사진·제목·날짜·목적지의 익숙한 순서 유지 | 사진 매핑과 페이지 이동 테스트 |
| P03 통제와 자유 | B-1/A-9/C-1 | 뒤로가기·취소·실행 취소 시연, 실제 삭제 없음 | 삭제/취소 뒤 데이터 불변 테스트 |
| P04 일관성 | A-1/B-2/C-5 | 공통 색상·사진·탭·카드 재사용 | 사진/탭/반응형 테스트 |
| P05 오류 예방 | A-9/A-11/B-5/B-8 | 확인 Dialog와 저장되지 않는다는 고지 | 폼 완료·취소 테스트 |
| P06 재인 | A-2/A-3/B-4/C-5 | 사진과 태그로 항목을 구별 | 카드/상세 표시 테스트 |
| P07 효율성 | A-7/A-8/B-6 | 검색·필터·정렬·추억 UI만 예시로 제공 | 고정 검색 결과·정렬 비변경 테스트 |
| P08 간결성 | A-3/B-3 | 사진 오버레이 없는 카드와 큰 상세 표지 유지 | 카드 버튼 위치·좁은 창 테스트 |
| P09 오류 복구 | A-5/A-12/B-7 | GET 실패 이유와 다시 시도 유지 | HTTP 오류·네트워크 오류·재시도 테스트 |
| P10 도움말 | A-10/C-4 및 시연 피드백 | 실제 통계·저장으로 오해하지 않도록 한국어 안내 | 시연 문구와 GET-only 부정 테스트 |

상태 계획은 코드의 // STATE:로만 남긴다. 네트워크 쓰기·영구 저장·실제 통계·국가 추론·추천은 구현하지 않는다.
