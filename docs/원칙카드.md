# Polarsteps v2 — Nielsen 원칙 카드

실제 사용자 리뷰나 영상은 제공되지 않았다. 아래 근거는 구현 구조와 회귀 테스트이며 리뷰를 지어내지 않는다.

| 원칙 | 적용 요소·화면 | 설계 판단 | 검증 |
|---|---|---|---|
| P01 상태 가시성 | A-4/A-6, B-7, C-3 | 비동기 GET 상태를 표시하고 현재 통계와 새로고침 초기화를 안내 | 로딩/오류/빈 상태와 집계·세션 초기화 테스트 |
| P02 실세계 일치 | A-2/B-3/B-9/C-2/C-6/C-8 | 여행 사진·제목·날짜·목적지의 익숙한 순서 유지 | 사진 매핑과 페이지 이동 테스트 |
| P03 통제와 자유 | B-1/A-9/B-5/C-1/C-7 | 뒤로가기·취소·메모리 삭제·실행 취소 | 삭제·복원 및 GET 원본 복구 테스트 |
| P04 일관성 | A-1/B-2/C-5 | 공통 색상·사진·탭·카드 재사용 | 사진/탭/반응형 테스트 |
| P05 오류 예방 | A-9/A-11/B-8 | 확인 Dialog와 날짜/필수 입력 검증 | 폼 완료·취소 테스트 |
| P06 재인 | A-2/A-3/B-4/C-4/C-5/C-6/C-8 | 사진·태그와 로컬 지도 Marker로 항목을 구별 | 카드/상세 표시 테스트 |
| P07 효율성 | A-7/A-8/B-6 | 실제 검색·필터·그룹 내 정렬과 추억 모달 | 검색/필터·정렬 결과 테스트 |
| P08 간결성 | A-3/B-3 | 사진 오버레이 없는 카드와 큰 상세 표지 유지 | 카드 버튼 위치·좁은 창 테스트 |
| P09 오류 복구 | A-5/A-12/B-7/C-9 | GET 실패 이유와 다시 시도 유지 | HTTP 오류·네트워크 오류·재시도 테스트 |
| P10 도움말 | A-10/C-7 및 삭제 확인·목적지 안내 | 메모리 변경·새로고침 초기화와 미인식 목적지 한국어 안내 | 세션 수명과 GET-only 부정 테스트 |

상태 변화는 // STATE:로 표시한다. 네트워크 쓰기·영구 저장·상태관리 프레임워크는 없다.
메모리 상태관리와 검색·정렬·통계·국가 인식·방문 지도 Marker 로직을 포함하므로 교수 감점 위험이 있다.
이는 기능 보존 요청에 따른 선택이며 완전한 감점 방지안은 아니다. 디자인가이드 11절을 참고한다.

C-8은 사진·날짜·Tag·후기를 포함하며 종료 여행만 생성한다. C-9는 사용자 요청 Web PNG 다운로드다.
미래/진행 여행 및 날짜 오류는 카드 생성을 막고 후기는 시작 후 허용한다(P05). 지도는 InteractiveViewer를 재사용한다.
PNG 다운로드도 교수의 저장/실제 로직 규칙 해석에 따라 감점 위험이 있으므로 가이드의 범위 설명을 함께 제시한다.
